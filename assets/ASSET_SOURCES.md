# Asset sources & licences

This file records every third-party visual asset bundled with AALUMAI, where it
came from, and the licence that allows redistribution inside the app.

AALUMAI is offline-first: all bundled assets below ship inside the app and work
without an internet connection. Custom images chosen by the user stay on the
device and are never uploaded.

## Bundled background images

All bundled backgrounds come from Wikimedia Commons and are either **Public
domain** or **CC0 1.0** (public-domain dedication). Neither licence requires
attribution, but the source and author are recorded here for provenance and
good practice. Images were downloaded as 1280&nbsp;px-wide JPEG thumbnails
(suitable for phone screens, cropped responsively at runtime) and kept small to
avoid bloating the app.

## Categories deliberately served by existing reusable artwork (no downloads)

The following asset categories requested for collection are already covered by
first-party, code-drawn artwork that ships with the app. Adding third-party
photos here would duplicate the existing visual language and, more importantly,
add unused assets, so nothing was downloaded for them:

- **Workout exercises** — `lib/features/fitness/widgets/exercise_art.dart`
  renders an original, consistent `ExerciseArt` illustration for every exercise
  category (arms, shoulders, chest, back, legs, core, cardio, yoga, warm-up),
  deliberately avoiding third-party photographs. Exercise detail screens already
  use it, so no per-exercise photos are needed.
- **Alarm challenges** — the ringing screen (`alarm_ringing_screen.dart`) draws
  math, memory and code challenges with Material icons and text only; it does
  not use image assets, so no new illustrations were added.
- **Learning & habits** — these screens use Material icons (`Icons.school`,
  `Icons.menu_book_outlined`, `Icons.local_fire_department`, check-circle
  icons, etc.). A single reusable icon per category is sufficient, so no
  vocabulary/category illustrations were downloaded.

If richer illustrations for these categories are wanted later, add them under
`assets/images/` **only when they are actually wired into a screen**, and record
each new file in the table above.

## Reproducing the downloads

Backgrounds were fetched from the Wikimedia Commons API
(`action=query&prop=imageinfo&iiurlwidth=1080`) using the file titles in the
table. To re-fetch, request the thumbnail URL for each title and save it to the
listed path. Keep new downloads to 1280&nbsp;px width or less and re-check the
licence before committing.
